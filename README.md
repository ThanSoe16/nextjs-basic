## 🛠 Configuration Tips

- **Enable absolute imports** by updating `tsconfig.json`:

  > This allows you to use paths like `@/components/...` instead of relative paths like `../../components`.

  ```json
  {
    "compilerOptions": {
      "baseUrl": ".",
      "paths": {
        "@/*": ["./src/*"]
      }
    }
  }
  ```
